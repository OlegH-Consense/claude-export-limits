Claude Bookmarklets

Two bookmarklets for claude.ai: export the current conversation and check your usage limits.

Drag a button onto your browser's bookmarks toolbar (Firefox: Ctrl+Shift+B shows the toolbar). Clicking it here does nothing.

Conversation exportv1.1

Saves the open Claude conversation as two files.

  • .json — raw API response: the whole tree, including alternative branches.
  • .md — the active branch: text, artifacts, attachment names.
  • Works on claude.ai/chat/<id> pages; dialog messages follow your browser language (EN / UK / RU).
Claude Export

Usage limitsv2

Shows a panel with your current usage limits, no need to open Settings.

  • QUOTA LEFT / USED — unused and used share of the quota window.
  • TIME LEFT / ELAPSED — remaining and elapsed share of the 5-hour or weekly window.
  • Refreshes automatically every minute while the panel is open.
  • The header shows your plan and organization (its ID when the name is a default “…'s Organization”).
  • Click again, press Esc or click the backdrop to close.
Claude Limits

If dragging doesn't work

  1. Click “Copy code” under the button you need.
  2. Create a new bookmark (Firefox: right-click the toolbar → “Add Bookmark…”).
  3. Paste the copied line into the “URL” / “Location” field; the name can be anything.

Both scripts talk only to claude.ai using your current session and send nothing to third-party sites.

They rely on internal, undocumented claude.ai endpoints; if Anthropic changes them, the script shows a message with the HTTP status.
